ProjectFirma 2.0 / Layout & Sections / Container

Container

Centered, max-width layout wrapper with a symmetric side gutter. The single place the kit owns “constrain page content to a readable width.”

Inherited .astro import EsaContainer from '@esa/ecology/esa-container.astro';

Preview

The container fills its parent, caps at maxWidth, centers, and applies a gutter on both sides. The dashed rule below marks its edges.

Widths

The 1556px default is the kit's wide app width — the same figure esa-app-bar centers its own bar at, so a bar and the content beneath it line up without either knowing about the other. Narrow it for reading-width layouts: article bodies, settings forms, single-column detail pages.

Gutter

The side gutter is --spacing-600 (32px), applied by the component as padding-inline. It is neither a prop nor a per-scope hook: every container on a page breathes the same amount, and a spoke that wants a different amount re-points --spacing-600 once, globally. There is no supported way to widen, narrow, or remove the gutter for one region.

API

PropTypeDefaultDescription
maxWidth string '1556px' Max content width, as any CSS length. The kit's wide page width by default.

Slots

SlotTypeDefaultDescription
default slot — The content being constrained.

Accessibility

  • Renders a plain <div> with no role — it is pure layout and adds nothing to the accessibility tree. Put landmarks (<main>, <section>) around or inside it, not on it.
  • Never remove the gutter globally to fit more in: text touching the viewport edge is a real readability and zoom problem at 320px.
  • The max-width caps the measure, not the font size. Long-form text still wants a narrower maxWidth — around 65–75 characters — rather than a wide container with big type.
