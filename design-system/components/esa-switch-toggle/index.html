Switch Toggle

An on/off switch for instant settings — a native <button role="switch"> with Space/Enter toggling and a sliding thumb. Form-associated; emits a composed change event.

Inherited wc import '@esa/ecology/esa-switch-toggle';

Preview

Sizes

Label position

Place the label after the track (default) or before it.

States

Form participation

A checked switch submits on under its name; off submits nothing. Submitting logs the alerts entry.

API

PropTypeDefaultDescription
label string '' Text rendered beside the track.
size 'xs' | 'sm' | 'md' | 'lg' 'md' Track and thumb size.
disabled boolean false Disables interaction.
name string | undefined — Form field name — the key this control submits under.
label-position 'before' | 'after' 'after' Whether the label sits before or after the track. Property: `labelPosition`.
checked boolean false On/off state of the switch.

Events

EventTypeDefaultDescription
change CustomEvent<{ checked: boolean }> — Fired when toggled. Composed and bubbling; detail.checked is the new state.
Binding these events from Angular

Every one of these is a CustomEvent, so the payload is on $event.detail — $event.target.value reads empty, with no error. The names are lowercase and Angular passes them to addEventListener verbatim, so camel-casing one means it never fires.

  • (change)="onChange($event.detail)"

Accessibility

  • Renders a native <button role="switch"> with aria-checked reflecting state.
  • Keyboard and activation come for free; Space/Enter toggle.
  • The disabled attribute disables the underlying button.
  • Visible focus ring on the track via --focus-ring-* tokens.
