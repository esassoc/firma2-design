# Projects index

Find a project, or the way back to one in progress. The Projects index is the table of every project (with a List view), searched and filtered in place; getting back to the projects a person had open recently has to be quicker than searching for them again.

## Decisions

| # | Decision |
|---|----------|
| 1 | Recently viewed lives in the table's search: focusing the empty search lists the last five projects opened in this browser, with when; typing hides the list and filters the table. The row of cards above the table is removed. Rejected in /proto/recent-projects: the card row (about 220px above the table on every visit), a one-line jump list (no stage, lead or when), and a "Recently viewed" view beside Table and List (one more click every time). *(2026-11-24)* |
| 2 | The global search opens on Recent: the last pages opened in this browser, any kind, the current page left out. Projects and pages read the same history. *(2026-11-24)* |
| 3 | The footer's Recent menu is removed; the two searches show the same history. *(2026-11-24)* |
| 4 | The Map view is removed from the Projects index; the Map page is where every project sits on one map. *(2026-11-24)* |
