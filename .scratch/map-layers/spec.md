# Map layers

An administrator sets what every map in the workspace is made of: the base map it opens on, how each project's work is coloured, and the reference boundaries drawn under it. A reader should be able to tell projects apart on any map without learning a colour scheme the rest of the product does not use.

## Decisions

| # | Decision |
|---|----------|
| 1 | On every map, a project's work areas, its pins and its zoomed-out dot wear one colour, and by default that colour is its stage's (the colour set on the Stages page). *(2026-11-24)* |
| 2 | Map layers has a workspace setting, "Color work areas by", that changes what the colour comes from: stage, project type, or a classification. *(2026-11-24)* |
