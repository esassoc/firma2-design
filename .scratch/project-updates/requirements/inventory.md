4. Is the import offered while the project page is in its reading state, or only after Edit is pressed? — The page has a view and an edit mode; the entry points ignore it today.

8. What happens on a project with no performance measures, or no closed reporting period to file under? — The measures card hides its button with no measures; the page itself has no such state.
9. What can fail on "Add N changes" (the record changed underneath, the save fails part-way), and is an import all-or-nothing? — Validation is all-or-nothing today; saving is unspecified.

13. What are the limits: file size (20 MB shown), file types (.doc, .xls, .txt are inconsistent), pages or rows in a document, length of pasted text, length of the note? — And what the person sees at each limit.
14. When two people import the same report, or someone edits a field while another has the check step open, which value stands and is anyone told? — "Already on file" is computed when the reading opens, not when Add is pressed.
15. Does adding an import notify anyone (the lead organization's managers), or does it only raise the unpublished-changes count? — No notification is shown.
